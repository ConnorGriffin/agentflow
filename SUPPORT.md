# Support

AgentFlow is maintained on a best-effort basis.

- Use GitHub Issues for reproducible bugs and narrowly scoped feature requests.
- Use `SECURITY.md` for vulnerabilities.
- Include the AgentFlow commit, macOS version, Python version, relevant tool
  versions, configuration with secrets removed, and minimal reproduction steps.
- Do not post credentials, private repository content, transcripts, or other
  sensitive data.

There is no guaranteed response time, uptime, compatibility window, migration
service, or private support channel. Sponsorship does not buy priority,
influence acceptance, or create a support agreement.
